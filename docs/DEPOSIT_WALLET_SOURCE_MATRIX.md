## Decision Vocabulary

Mismatch status values:
- `aligned`: reviewed docs, official SDK, local docs, and fixtures do not conflict for this row.
- `doc-sdk-mismatch`: public documentation and official SDK or another official guide disagree.
- `fixture-provenance-gap`: local fixture lacks inline metadata and is covered by `tests/fixtures/deposit_wallet/PROVENANCE.md`.
- `local-synthetic-only`: fixture is synthetic edge/regression data and is not canonical wire authority.

Fallback decision values:
- `official-sdk-authoritative`: use pinned official SDK source for local fixture/test behavior.
- `official-doc-authoritative`: use the current official docs page for local documentation and future work.
- `sanitized-fixture-authoritative`: use a sanitized pinned fixture only for existing offline tests.
- `no-live-change-pending-human`: block live-capable changes until explicit human review or newer official evidence resolves the mismatch.

Live-change gate values:
- `docs-fixtures-only`: safe for documentation and offline fixture tests only.
- `read-only-only`: safe only for read-only endpoint or parser evidence.
- `blocked-live`: no live relayer mutation, wallet deployment, signing, or trading behavior may be enabled from this row alone.
