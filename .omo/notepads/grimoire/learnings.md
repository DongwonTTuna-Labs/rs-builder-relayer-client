The official action definition runs exactly `opencode github run`; source `github.handler.ts` creates/sends a prompt via `prompt.prompt(...)` for the event. The model may do normal agentic multi-step work until idle, but the Action itself does not document an internal autonomous continuation loop like `--continue` or OMO/Boulder. However current source omits `agent` when invoking `prompt.prompt`, and issue #21730 documents that `agent:` is ignored by the binary. Therefore grimoire GitHub Action should rely on config `default_agent`, not only `with.agent`, until upstream fixes this. Sources: `https://opencode.ai/docs/github/#configuration`, `https://github.com/anomalyco/opencode/blob/7c1e61af1e0a19f77fe1e9de210bd565ead8e993/github/action.yml#L12-L14`, `https://github.com/anomalyco/opencode/blob/7c1e61af1e0a19f77fe1e9de210bd565ead8e993/github/action.yml#L71-L79`, `https://github.com/anomalyco/opencode/blob/7c1e61af1e0a19f77fe1e9de210bd565ead8e993/packages/opencode/src/cli/cmd/github.handler.ts#L895-L904`, `https://github.com/anomalyco/opencode/issues/21730`.
